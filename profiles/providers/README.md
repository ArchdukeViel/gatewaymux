# Provider Profiles

Contains built-in provider profiles for first-class providers:
- `nvidia.toml`: NVIDIA NIM hosted API capabilities, endpoints, and default quotas.
- `antigravity.toml`: Antigravity connector OAuth specifications and rate policies.
- `poolside.toml`: Poolside inference endpoints and model families.
- `openrouter.toml`: OpenRouter global, US-region, and EU-region deployment profiles.
- `ollama.toml`: Ollama Cloud endpoints and contracts.
- `custom.toml`: Custom Endpoint default template and probing policies.
