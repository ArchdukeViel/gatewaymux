# Architecture Decision Records (ADRs)

This directory records architecturally significant decisions for GatewayMux.

## Process
- Any substantial architecture, technology selection, or protocol decision not fully settled by the PRD requires an ADR.
- ADRs must be authored using [`template.md`](template.md).
- Status flows: `Proposed` -> `Accepted` | `Rejected` -> `Superseded`.
